🌱 Raízes

As raízes são órgãos vegetais que geralmente se desenvolvem no solo.

Elas são importantes para a fixação da planta e para a absorção de água e sais minerais.

Principais funções

  • Fixação da planta.
  • Absorção de água.
  • Absorção de sais minerais.
  • Armazenamento de substâncias em algumas plantas.

Tipos de raízes

Existem diferentes tipos de raízes, como pivotantes, fasciculadas e adventícias.
