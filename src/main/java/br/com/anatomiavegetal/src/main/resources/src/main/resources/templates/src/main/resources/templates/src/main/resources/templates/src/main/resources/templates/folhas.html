🍃 Folhas

As folhas são estruturas importantes das plantas e participam principalmente da fotossíntese.

Principais funções

  • Realizar a fotossíntese.
  • Participar das trocas gasosas.
  • Auxiliar na transpiração.
  • Produzir substâncias importantes para a planta.

Partes da folha

Uma folha pode apresentar limbo, pecíolo e nervuras.

O formato e o tamanho das folhas variam entre as espécies.
